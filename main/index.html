FIFO
First In, First Out

O processo que chegou primeiro é o primeiro a usar a CPU. Sem preempção — cada processo roda até terminar completamente.

Execute quem chegou primeiro
Sem interrupção: roda até terminar
Empate de chegada: menor ID primeiro

SJF
SJF
Shortest Job First

Quando a CPU fica livre, escolhe o processo com o menor burst total entre os que já chegaram. Sem preempção.

CPU livre → escolhe menor burst
Sem interrupção: roda até terminar
Empate de burst: menor ID primeiro

SRTF
SRTF
Shortest Remaining Time First

A cada ciclo, roda o processo com o menor tempo restante. Um processo pode ser interrompido se um novo chegar com burst menor.

Sempre executa o menor tempo restante
Preemptivo: novo processo pode interromper
Empate: menor ID primeiro

RR
Round Robin
Quantum = 3 ciclos

Cada processo recebe no máximo 3 ciclos (quantum) por vez. Depois volta para o fim da fila. Justo e preemptivo por tempo.

Cada processo roda até 3 ciclos por vez
Ao esgotar quantum, volta para o fim da fila
Fila FIFO: primeiro a chegar, primeiro a sair
